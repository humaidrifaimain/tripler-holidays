🚀 DEPLOY IN 3 COMMANDS (Linux/Mac):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Command 1: BUILD
┌─────────────────────────────────────────┐
│ npm run build                           │
│ ⏱️ Takes: 2-3 minutes                    │
│ Creates: out/ folder with static site   │
└─────────────────────────────────────────┘

Command 2: ZIP
┌─────────────────────────────────────────┐
│ cd out && zip -r -9 ../tripler-site.zip . && cd ..  │
│ ⏱️ Takes: 1-2 minutes                    │
│ Creates: tripler-site.zip (~270 MB)    │
└─────────────────────────────────────────┘

Command 3: UPLOAD
┌─────────────────────────────────────────┐
│ cPanel → File Manager                   │
│ → /public_html/                         │
│ → Upload tripler-site.zip               │
│ → Extract/Decompress                    │
│ ⏱️ Takes: 5-10 minutes                   │
└─────────────────────────────────────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 COPY-PASTE COMMANDS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# Mac/Linux Terminal:

npm run build && cd out && zip -r -9 ../tripler-site.zip . && cd .. && echo "✅ Done! Upload tripler-site.zip to cPanel"


# Windows PowerShell:

npm run build; cd out; Compress-Archive -Path "*" -DestinationPath "../tripler-site.zip" -Force; cd ..; Write-Host "✅ Done! Upload tripler-site.zip to cPanel"
